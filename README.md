# dp-physics-lab
DP Physics Lab - Y12 virtual practicals (A.2 Forces and momentum)

Open: https://mortadan-lgtm.github.io/dp-physics-lab/

Each practical has an interactive bench built from photos of real apparatus. Students drag masses, carts, sensors and clamps, take repeat readings with realistic scatter and systematic errors, then process, graph and evaluate them. Progress is saved in the browser only.
